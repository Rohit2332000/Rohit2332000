I build **intelligent, end-to-end AI applications that solve real-world problems** — from understanding business requirements and engineering data pipelines to developing LLM workflows, APIs, and cloud deployments.

My focus is on building AI systems that go beyond prototypes by combining retrieval, tool use, machine learning, evaluation, observability, and deployment into practical solutions.

- 🤖 Building agentic AI systems with LangGraph, LangChain, and MCP.

## 🚀 Featured Projects

### 1. 📊 AI-Powered Retail Sales Forecasting & Decision Support Platform

An end-to-end, FDE-inspired AI platform that transforms retail data into actionable insights through **30-day sales forecasting and GenAI-powered business analytics**.

**What I built**

- 🏗️ Developed a Databricks Bronze → Silver → Gold data pipeline.
- 📈 Built sales forecasting workflows with MLflow experiment tracking and model versioning.
- 💬 Integrated a GenAI assistant for natural-language business queries.
- 🔄 Implemented data uploads, pipeline execution, and model retraining workflows.
- ⚡ Developed a React + Vite frontend and FastAPI backend.
- 🐳 Containerized services with Docker and deployed on AWS EC2.
- 🌐 Configured NGINX load balancing across multiple backend instances.
- 🔁 Worked on GitHub Actions CI/CD workflows.

**Tech Stack:** Databricks, MLflow, Python, GenAI, FastAPI, React, Docker, AWS EC2, NGINX, GitHub Actions

🔗 [Backend Repository](https://github.com/Rohit2332000/AI-Powered-Retail-Sales-Forecasting-System) · [Frontend Repository](https://github.com/Rohit2332000/AI-Powered-Retail-Sales-Forecasting-System-Frontend) · [Experimentation Dataset](https://drive.google.com/drive/folders/1Rh1YtKZTXukYIgCtDDFW6H31ZAbgabEM?usp=sharing)

### 2. 🤖 Agentic AI Assistant with MCP Integration

Built a tool-using AI assistant that executes multi-step tasks by integrating LLMs, LangGraph, and custom Model Context Protocol (MCP) servers.

- 🛠️ Integrated tools for expense management, web search, weather, stock information, and more.
- 🔌 Developed custom MCP servers and connected remote tools.
- 🗄️ Built a FastAPI backend with PostgreSQL.
- 🔍 Integrated LangSmith tracing for workflow observability.

**Tech Stack:** Python, LangGraph, LangChain, MCP, FastAPI, PostgreSQL, LangSmith, Docker

🔗 [GitHub Repository](https://github.com/rohit2332000/mcp-powered-assistant)

### 3. ✈️ Aircraft Maintenance Intelligence System

Developed an AI-powered maintenance intelligence system combining telemetry anomaly detection, retrieval-augmented generation, and LLM-based maintenance recommendations.

- 📉 Analyzed telemetry patterns to identify potential anomalies.
- 📚 Retrieved relevant maintenance knowledge using RAG.
- 🧠 Combined retrieved context with LLM-generated recommendations.

**Tech Stack:** Python, Machine Learning, RAG, LLMs, Embeddings

🔗 [GitHub Repository](https://github.com/rohit2332000/aircraft-maintenance-intelligence)

### 4. 🔎 RAG Evaluation with DeepEval

Built an evaluation workflow for assessing retrieval and generation quality in RAG applications.

- 🧪 Evaluated retrieval and response quality using component-level metrics.
- 📋 Worked with golden datasets and configurable evaluation thresholds.
- 📊 Used evaluation results to identify weaknesses in RAG pipelines.

**Tech Stack:** Python, DeepEval, RAG, LLM Evaluation

🔗 [GitHub Repository](https://github.com/rohit2332000/RAG_EVALUATION_using_DeepEVAL)

### 5. 🌍 Agentic Trip Planning System

Developed an agentic travel-planning application that generates personalized itineraries using coordinated workflows and live information sources.

- 🧭 Used LangGraph to orchestrate planning and validation.
- 🌦️ Integrated weather, web research, geolocation, and routing services.
- 🖥️ Built a FastAPI backend and Streamlit interface with itinerary export.

**Tech Stack:** Python, LangGraph, FastAPI, Streamlit, Groq, LangSmith

🔗 [GitHub Repository](https://github.com/rohit2332000/agentic-trip-planning-system)

### 6. 🖼️ Multimodal RAG System

Built an intelligent knowledge assistant for searching across YouTube videos, PDFs, and documents.
